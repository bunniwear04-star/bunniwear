โจทย์ปัญหาและที่มาของโครงการ (? และ Review)

❓ ที่มาของปัญหา (Problem Statement)

ร้านเสื้อผ้าแฟชั่นสไตล์เกาหลี-มินิมอล bunniwear ต้องการระบบหน้าร้านออนไลน์ที่ช่วยให้ลูกค้าเลือกชมสินค้า เลือกสีและไซส์ คำนวณส่วนลด สรุปยอดสั่งซื้อส่งทาง LINE และสามารถออก ใบเสนอราคา (Quotation) ขนาด A4 เป็นไฟล์ PDF ได้ทันที โดยไม่ต้องพึ่งพาระบบฐานข้อมูลหรือเซิร์ฟเวอร์หลังบ้าน (No Backend) เพื่อประหยัดค่าใช้จ่ายและดูแลรักษาง่าย

🔍 การทบทวนความต้องการ (Review)

  • ทำงานจบในไฟล์ index.html เพียงไฟล์เดียว เปิดใช้งานได้ทันที
  • จดจำรายการสินค้าในตะกร้าได้แม้ปิดหรือรีเฟรชหน้าเว็บด้วย LocalStorage
  • มีระบบช่วยคำนวณไซส์อัตโนมัติ และหน้าต่างดูรายละเอียดสินค้าแบบขยาย (Quick View)
  • รองรับทั้งลูกค้าซื้อปลีก และลูกค้าองค์กรที่ต้องการใบเสนอราคา PDF

ความต้องการของระบบ (FR & NF) และอุปกรณ์ (HW)

3.1 Functional Requirements (FR: ระบบทำอะไรได้บ้าง)

  1. ระบบแคตตาล็อกและค้นหา: กรองสินค้าตาม 5 หมวดหมู่ ค้นหาชื่อสินค้า และเรียงลำดับตามราคา/ความนิยม
  2. ระบบ Quick View: แสดงป๊อปอัปภาพขนาดใหญ่ จุดเด่นเนื้อผ้า เลือกสี ไซส์ และจำนวนชิ้น
  3. ระบบตารางไซส์อัจฉริยะ: รับค่ารอบอกและรอบเอว (นิ้ว) เพื่อประมวลผลแนะนำไซส์ (S, M, L, Free Size)
  4. ระบบตะกร้าและโปรโมชั่น: เพิ่ม/ลดจำนวนสินค้า คำนวณสิทธิ์ส่งฟรีเมื่อครบ ฿990 และลด 10% เมื่อใช้โค้ด BUNNI10
  5. ระบบใบเสนอราคา (Quotation PDF): กรอกชื่อลูกค้า/บริษัท เลขผู้เสียภาษี คำนวณ VAT 7% แปลงยอดเงินเป็นตัวอักษรไทย และพิมพ์/โหลด PDF ขนาด A4
  6. ระบบสรุปออเดอร์และแชท LINE: สร้างใบสรุปคำสั่งซื้อพร้อมปุ่มลอยแชท LINE @bunniwear

3.2 Non-Functional Requirements (NF: คุณภาพของระบบ)

  • Performance: โหลดหน้าเว็บไว คำนวณราคาและสลับหมวดหมู่แบบ Real-time ทันทีโดยไม่รีโหลดหน้า
  • Responsiveness: รองรับการแสดงผลทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์
  • Persistence: บันทึกข้อมูลตะกร้าลงใน LocalStorage ของเบราว์เซอร์อัตโนมัติ
  • Portability: ไม่ต้องใช้เซิร์ฟเวอร์ฐานข้อมูลหลังบ้าน โฮสต์ฟรีบน GitHub Pages ได้ทันที

4. Hardware & Environment (HW: สเปกเครื่องและสภาพแวดล้อม)

  • ฝั่งผู้ใช้งาน (Client): สมาร์ทโฟน (iOS/Android) หรือคอมพิวเตอร์ทั่วไปที่มีเว็บเบราว์เซอร์ (RAM ขั้นต่ำ 2 GB)
  • ฝั่งนักพัฒนา (Dev PC): คอมพิวเตอร์ที่บ้านและที่ทำงาน เชื่อมต่อผ่าน Git และ GitHub Desktop
  • Hosting: GitHub Repository (bunniwear04-star/bunniwear)

5.3 การออกแบบ UX/UI

  • Mood & Tone: สไตล์ Seoul Minimal Studio ใช้สีครีมพาสเทล (#fdf8f6) และสีโรสโกลด์-พีช (#da7b5b)
  • Typography: ใช้ฟอนต์ Playfair Display สำหรับโลโก้แบรนด์ และฟอนต์ Prompt สำหรับภาษาไทย
  • Single-Page Experience: เลือกสี/ไซส์บนการ์ดได้ทันที มีแถบแจ้งเตือนยอดส่งฟรีอัตโนมัติในตะกร้า
  • Print-First Quotation: ใช้ @media print ซ่อนปุ่มหน้าเว็บทั้งหมดเมื่อสั่งพิมพ์ เหลือเฉพาะกระดาษใบเสนอราคา A4

🛠️ 6. การพัฒนาโปรแกรม (Development Stack)

พัฒนาด้วย HTML5, Tailwind CSS, Vanilla JavaScript (ES6+), Lucide Icons และ html2pdf.js โดยรวมโค้ดไว้ในไฟล์ index.html เพียงไฟล์เดียว พร้อมฟังก์ชันแปลงจำนวนเงินเป็นตัวอักษรภาษาไทย (numberToThaiBahtText) และบริหารจัดการโค้ดร่วมกันระหว่างคอมพิวเตอร์ที่บ้านและที่ทำงานผ่าน GitHub (SSH Key Authentication)
