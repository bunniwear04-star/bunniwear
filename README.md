# โครงงานระบบเว็บไซต์ร้านขายเสื้อผ้าแฟชั่นและออกใบเสนอราคาออนไลน์ (ร้าน bunniwear)

โครงงานนี้เป็นส่วนหนึ่งของการศึกษารายวิชาการวิเคราะห์และออกแบบระบบ ปีการศึกษา 2569

## คณะผู้จัดทำ
1. น.ส.อุษณีย์ ฉัตรสิริสุข รหัสนักศึกษา 6735C10013
2. น.ส.บัณฑิา ป้องงาม รหัสนักศึกษา 6735C10024

## เสนอ
ผศ.ดร.ณัฏฐ์ โอธนาทรัพย์

## รายละเอียดไฟล์ในโครงงาน
- `index.html` — ไฟล์ระบบเว็บไซต์หน้าร้าน bunniwear (แคตตาล็อกสินค้า 16 รายการ, ระบบค้นหาและกรองหมวดหมู่, โปรแกรมคำนวณไซส์, ตะกร้าสินค้า LocalStorage, ระบบออกใบเสนอราคา A4/PDF และระบบสรุปคำสั่งซื้อส่งทาง LINE)
- `logo.png` — รูปโลโก้ร้าน bunniwear
- `report-bunniwear.html` — ไฟล์ต้นฉบับรายงานการวิเคราะห์และออกแบบระบบ (ฟอนต์ TH SarabunPSK)
- `Bunniwear_Report_Final.pdf` — ไฟล์รายงานการวิเคราะห์และออกแบบระบบ ฉบับสมบูรณ์พร้อมพิมพ์ (ขนาด A4 จำนวน 9 หน้า)
- `system-design-doc.html` — หน้าสรุปเอกสารการวิเคราะห์และออกแบบระบบสำหรับเปิดดูผ่านหน้าเว็บไซต์
- `fonts/` — โฟลเดอร์เก็บไฟล์ฟอนต์ TH SarabunPSK สำหรับแสดงผลรายงาน

## วิธีการเปิดใช้งาน
ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ (เช่น Google Chrome หรือ Microsoft Edge) เพื่อเข้าใช้งานระบบเว็บไซต์ได้ทันที
